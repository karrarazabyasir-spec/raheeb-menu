# نظام المينيو والطلب الإلكتروني — مطعم «رهيب» 🍽️🔥
> الإصدار 1.1 — بنية متكاملة لفرع واحد، دفع نقدي، PWA فائق السرعة، ودعم كامل للغات (عربي RTL / إنجليزي LTR).

---

## 🌟 نظرة عامة على النظام

نظام متكامل للمينيو والطلب الذاتي لمطعم **«رهيب»** عبر مسح رموز الـ QR بدون تحميل أي تطبيق، يخدم الصالة (الطلب من الطاولة) والطلب المسبق للاستلام (Takeaway)، مع شاشات تشغيلية لحظية ومخصصة.

### 🎨 الهوية البصرية
- **الاسم:** مطعم رهيب (Raheeb Restaurant)
- **اللون الأساسي:** العنابي الملكي `#780000` مشتق منه لوحة ألوان دافئة وفخمة، مع لمسات الذهب `#c68a2c` للأزرار والوسوم، وخلفيات ناصعة ومريحة للعين.
- **الخط المعتمد:** خط Cairo العربي الحديث فائق الوضوح وسريع التحميل.

## 📱 الشاشات وروابط الوصول

| الشاشة | المسار | الوظيفة |
| :--- | :--- | :--- |
| **واجهة الزبون (QR طاولة)** | `/?table=3` | مينيو تفاعلي، يعرف رقم الطاولة تلقائياً، تخصيص الأصناف، سلة، استدعاء نادل، طلب حساب. |
| **واجهة الزبون (استلام خارجي)** | `/` | طلب مسبق للاستلام، إدخال الاسم ورقم الجوال وموعد الاستلام. |
| **تتبع الطلب المباشر** | `/order/[id]` | شاشة حية لمتابعة مراحل التحضير، إرسال الطلب لواتساب المطعم مجاناً (`wa.me`)، وتقييم التجربة. |
| **شاشة الكاشير والصالة** | `/cashier` | استقبال الطلبات الحية مع تنبيه صوتي، خريطة الطاولات الحية، قبول/رفض، طلب يدوي، طباعة حرارية (80mm/58mm)، وزر وضع الصنف «نفد». |
| **شاشة المطبخ (KDS)** | `/kitchen` | شاشة مهيأة للتابلت وللتحكم باللمس، تعرض التذاكر مرتبة بالأقدم أولاً، عدّاد زمني تصاعدي، وأزرار "بدأ التحضير" ⬅️ "جاهز"، وإبراز الملاحظات الحساسة. |
| **لوحة تحكم المالك** | `/admin` | تقارير المبيعات، إدارة المينيو والأصناف، توليد وطباعة بطاقات QR للطاولات، إعدادات الواتساب، وإيقاف/تفعيل الطلبات. |

## 🛠️ المكدس التقني (Tech Stack)

- **الواجهة الأمامية والخادم:** Next.js 16 (App Router) + TypeScript + React 19.
- **التصميم والتنسيق:** Tailwind CSS v4 + Lucide Icons + خط Cairo العربي.
- **محرك البيانات:** مسار بيانات محلي آمن ومثابر `data/store.json` مع تحقق إلزامي من الأسعار والخيارات من جهة الخادم (Server-side validation).
- **التحديث اللحظي:** Server-Sent Events (SSE) عبر `/api/events` مع تنبيهات Web Audio API صوتية فورية.
- **توليد QR:** توليد رموز QR متجهة عالية الدقة لكل طاولة وللاستلام الخارجي مع إمكانية التنزيل الفوري بصيغة PNG أو الطباعة المباشرة.
- **الطباعة الحرارية:** دعم أنماط الطباعة الصامتة والحرارية بمقاس 80mm و 58mm لفاتورة الزبون وتذكرة المطبخ.

## 🚀 طريقة التشغيل محلياً

```bash
# تثبيت الحزم (تم مسبقاً)
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة الإنتاجية

npm start
```
